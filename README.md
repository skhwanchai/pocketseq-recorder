# Pocket Seq · อัดเสียงและสูตรเพลง

เว็บแอปคู่กับเครื่อง **Pocket Seq** (Raspberry Pi Pico 2 W) มี 2 แท็บ

- **อัดเสียง** อัดเพลงจากเครื่องผ่านสาย USB แล้วบันทึกเป็นไฟล์ `.wav`
- **ทำดนตรี** คลังสูตร 44 เพลง + 9 เมโทรนอม เลือกแนวได้ ลองฟังเสียงตัวอย่างในเว็บ แล้วดูวิธีกดบนเครื่อง

**เปิดใช้งาน:** https://skhwanchai.github.io/pocketseq-recorder/

## ต้องมี
- เฟิร์มแวร์ Pocket Seq **v2.2** ขึ้นไป
- Google Chrome หรือ Microsoft Edge บนคอมพิวเตอร์ (ใช้ Web Serial)
- ปิด Serial Monitor ใน Arduino IDE ก่อนเชื่อมต่อ

## วิธีใช้แท็บทำดนตรี
1. เลือก **เพลง** หรือ **เมโทรนอม** แล้วกดแนวที่ต้องการ (Lofi, Hip-Hop, ไทย, คริสต์มาส ฯลฯ)
2. กด ▶ บนการ์ดเพื่อลองฟัง หรือกดการ์ดเพื่อดูตารางกลอง เมโลดี้ และวิธีพิมพ์เข้าเครื่อง
3. ในหน้ารายละเอียด ปรับ BPM และปิด/เปิดเสียงแต่ละแทร็กได้ เว็บจำ BPM ที่ปรับไว้ให้

## วิธีใช้แท็บอัดเสียง
1. เสียบสาย USB แล้วกด **เชื่อมต่อเครื่อง** เลือกพอร์ตของ Pico
2. กดปุ่มแดง แล้วกด **PLAY** บนเครื่อง
3. กดหยุดบนเครื่อง ไฟล์ `.wav` จะดาวน์โหลดให้อัตโนมัติ

ไฟล์เสียง 22,050 Hz โมโน 16 บิต · ไฟล์อยู่ในเครื่องผู้ใช้เท่านั้น ไม่ถูกส่งขึ้นเซิร์ฟเวอร์

## ไฟล์ในโปรเจกต์
| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | หน้าเว็บ แท็บอัดเสียง และสไตล์ทั้งหมด |
| `music.js` | แท็บทำดนตรี: รายการ ตัวกรอง หน้ารายละเอียด และเสียงตัวอย่าง (Web Audio) |
| `recipes.js` | ข้อมูลสูตรเพลงและเมโทรนอมทั้งหมด |
| `manifest.webmanifest` | ข้อมูลแอปสำหรับติดตั้งเป็นแอปบน Mac |
| `sw.js` | เก็บหน้าเว็บไว้ เปิดได้แม้ไม่มีเน็ต |
| `icon.svg`, `icon-*.png` | ไอคอนแอป |
